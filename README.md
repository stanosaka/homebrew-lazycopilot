# Stanosaka Lazycopilot

## How do I install these formulae?

`brew install stanosaka/lazycopilot/<formula>`

Or `brew tap stanosaka/lazycopilot` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "stanosaka/lazycopilot"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
